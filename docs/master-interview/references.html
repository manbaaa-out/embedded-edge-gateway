资料与校对记录

技术结论优先采用标准、原厂手册、官方源码和高校原始材料。

原有机制在 2026-09-20/21 校对，FreeRTOS 移植专题在 2026-09-24 补充，多事件循环与 Boost.Beast 专题在 2026-10-04 核对。以下记录说明实际核对范围，部分基础资料保留 2026-09-18 的读取日期；访问限制单独标明。上游文档与工作区版本可能不同，项目行为以源码快照为准。

C++ 生命周期与共享所有权

区分对象寿命、指针变量同步和被指数据同步；std::move 是转换，扩容失效与异常保证按具体操作解释。

定位：RAII/构造失败；shared_ptr 原子访问；vector.modifiers

C++ Core Guidelines · C++ 工作草案：shared_ptr · C++ 工作草案：move / forward · C++ 工作草案：vector modifiers

语言优化与 volatile

volatile 不提供线程同步；发布普通数据需要满足同步关系。补充了 release/acquire 一次性发布示例和溢出反例。

定位：GCC Volatiles；C++ atomics.order；C 对象表示与整数规则

GCC：Volatiles · C++ 工作草案：原子内存序 · WG14 N1570：C11 委员会草案

条件变量与 futex

谓词必须在同一同步协议下检查与修改；通知不保存业务条件，futex 也不是可直接替代完整互斥量的全部机制。

定位：pthread_cond_wait 的原子解锁/等待；futex 的等待/唤醒基础

pthread_cond_wait(3p) · Linux futex(7)：用户态快速路径与内核等待 · pthread_mutex_lock(3p)

epoll 公平性与 ET

ET 读到 EAGAIN 是常规策略；若限制单轮工作量，必须另外保留就绪任务，避免既饥饿又漏后续处理。

定位：epoll(7) Questions and answers、Possible pitfalls

epoll(7) · read(2) · write(2)

fd、信号与合并通知

eventfd 用于唤醒，业务队列才保存命令；创建线程前屏蔽指定信号，使掩码继承到工作线程。

定位：eventfd 计数语义；signalfd 的线程信号掩码

eventfd(2) · signalfd(2)

超时的时钟与观测延迟

分开系统休眠计时、RTO、整体截止时间与回调实际执行；重传样本存在歧义，TCP 的数值规则不机械套用自定义协议。

定位：timerfd CLOCK_MONOTONIC/BOOTTIME；RFC 6298 §2、§3、§5

timerfd_create(2) · RFC 6298：TCP RTO 计算

SR 窗口与循环序号

给出 M=8、W=5 的旧帧歧义推演，并解释 2W≤M 的条件；会话内不复用是另一项约束。

定位：MIT 第 20 章；16.36 Lecture 18 SRP Rules；RFC 1982

MIT 6.02：可靠传输与 ARQ 课程原稿 · MIT 16.36：GBN 与 Selective Repeat · RFC 1982：Serial Number Arithmetic

确认、执行与幂等

协议 ACK、业务执行和结果缓存回收不同；幂等约束预期效果，不承诺所有响应相同。

定位：MQTT 3.1.1 §4.3；HTTP §9.2.2；ARQ 交付

OASIS MQTT 3.1.1 · RFC 9110：HTTP 幂等语义 · MIT 6.02：可靠传输与 ARQ 课程原稿

TCP 的字节流与关闭

TCP 不保留应用消息边界；四次挥手是常见交互而非固定报文数，TIME_WAIT 与连接代际及最后 ACK 有关。

定位：RFC 9293 的序号、状态、TIME-WAIT；拥塞控制规范

RFC 9293：TCP · RFC 5681：TCP Congestion Control

MQTT 会话与 QoS

QoS 的交付语义作用于协议链路；Clean Session、Retain 与应用业务去重分别说明，不承诺外部副作用恰好一次。

定位：OASIS MQTT 3.1.1 §3.1.2、§3.3、§4.3

OASIS MQTT 3.1.1 · Eclipse Mosquitto：C API

HTTP 请求定界

处理长度、传输编码、持续连接和错误边界；受限服务应明确不支持的特性，不能把一次读取视为整条请求。

定位：RFC 9112 §6、§9；RFC 9110

RFC 9112：HTTP/1.1 · RFC 9110：HTTP 幂等语义

SQLite 并发边界

WAL 仍是单写者；连接内部安全不等于跨多个 API 的业务事务自动隔离，长读事务会影响检查点。

定位：SQLite threading modes 与 WAL concurrency/checkpoint

SQLite：Using SQLite in multi-threaded applications · SQLite：Write-Ahead Logging

SQLite 持久性

NORMAL 可在掉电时回退最近提交，不能等同每次提交物理持久；应用封装必须检查阶段错误。

定位：PRAGMA synchronous 的 WAL/NORMAL；transaction 的失败语义

SQLite：PRAGMA synchronous · SQLite：Transaction

索引与绑定

索引服务访问路径，绑定服务参数解释及寿命；空结果与查询失败需要独立表示。

定位：Query Planning 多列索引；sqlite3_bind 生命周期

SQLite：Query Planning · SQLite：Binding values to prepared statements

Cortex-M3 异常帧

基本帧为 8 字，另可能有对齐填充；中断执行栈、被打断线程的入栈位置与 EXC_RETURN 分开解释。

定位：PM0056 Rev 7 异常进入/返回与栈；CMSIS MSP/PSP

ST PM0056：Cortex-M3 编程手册 · Arm CMSIS：内核寄存器

NVIC 与 BASEPRI

区分 CMSIS 逻辑值和左移编码；BASEPRI 不屏蔽所有中断，能够越过内核保护的 ISR 不得调用相关内核 API。

定位：优先级寄存器、分组、FreeRTOS 中断阈值

ST PM0056：Cortex-M3 编程手册 · Arm CMSIS：NVIC 接口与优先级 · FreeRTOS：Cortex-M interrupt priorities

STM32 时钟与寄存器

定时器倍频仅用于适用的时钟树；UART 线路完成、DMA 传输完成与软件回调是不同里程碑。RM0008 大文件访问限制时同时对照本地寄存器与 HAL 实现。

定位：RM0008 RCC、TIM、USART、DMA、IWDG；本地 HAL

ST RM0008：STM32F1 参考手册 · ST STM32F103x8/xB 数据手册 · ST PM0056：Cortex-M3 编程手册

I²C 电气约束

Rp 上限由上升时间和电容约束，下限由灌电流约束；九个时钟针对部分 SDA 卡低状态，不保证 SCL 卡低时恢复。

定位：NXP UM10204 Rev 7 §7 上拉设计、bus clear

NXP UM10204：I2C-bus specification

BH1750 模式与转换

默认高分辨率模式典型 120 ms、最大 180 ms，默认结果系数 1.2；地址位表示与 HAL 参数格式分开解释。

定位：ROHM Rev.B 电气表、指令表、I²C 测量示例

ROHM BH1750FVI 原厂手册（DFRobot 镜像）

DHT11 的版本差异

读取间隔大于 2 s；温度小数/符号与湿度小数规则不能泛化到所有名为 DHT11 的资料。应用允许更短间隔是当前待改进点。

定位：V1.3_20170331 表 3、§6、§7、表 4

奥松 DHT11 V1.3 产品手册

DMA 缓冲所有权

循环 DMA 不等待消费者归还内存；IDLE 是进度事件，环形指针差不足以识别任意多次绕圈。AN2548 本轮可检索，全文抓取受限。

定位：AN2548 的 DMA 原理；UART HAL；StreamBuffer 返回值

ST AN2548：DMA 控制器原理 · ST RM0008：STM32F1 参考手册 · FreeRTOS 官方 StreamBuffer 接口契约

FreeRTOS 任务调度

任务就绪不等于已运行；SysTick 请求切换、PendSV 执行保存恢复；并非每 Tick 都切换。

定位：官方内核书任务章；ARM_CM3 的 SVC/PendSV/SysTick

FreeRTOS 官方内核书：Task Management · FreeRTOS 官方 ARM_CM3 移植源码

FreeRTOS 队列与流缓冲

按值队列和指针队列有不同寿命责任；StreamBuffer 不保留消息边界，触发水位不等于帧长，ISR 发送必须处理实际写入量。

定位：队列复制和等待；流缓冲单写/单读与触发水位

FreeRTOS 官方内核书：Queue Management · FreeRTOS 官方 queue.h 接口契约 · FreeRTOS 官方 StreamBuffer 接口契约

FromISR 与唤醒

普通 API 的等待时间设零不能自动变为 ISR API；woken 应累计，最后请求切换。

定位：官方内核书 Interrupt Management；移植层屏蔽与 yield

FreeRTOS 官方内核书：Interrupt Management · FreeRTOS：Cortex-M interrupt priorities · FreeRTOS 官方 ARM_CM3 移植源码

互斥量优先级继承

继承减少无关中优先级任务干扰，不缩短硬件转换；多锁和超时路径取决于简化实现，不能宣称完整任意依赖图继承。

定位：官方资源管理章；basic priority inheritance 文档

FreeRTOS 官方内核书：Resource Management · FreeRTOS：Mutexes

任务通知、定时器和事件组

定时器回调由服务任务串行执行；事件位合并而不计数，ISR 事件置位可能依赖定时器命令队列。具体节点行为另核对内嵌源码。

定位：官方内核书；EventGroupSetBitsFromISR 的延后处理

FreeRTOS 官方内核书：Software Timer Management · FreeRTOS 官方内核书：Event Groups · FreeRTOS 官方内核书：Task Notifications · FreeRTOS：Software timers

堆、栈与内存预算

栈深度按元素而非字节，任务 PSP 与中断 MSP 分开；历史高水位不能证明未执行路径安全。

定位：heap_1 至 heap_5；任务创建参数与栈高水位

Tickless 与时基

入睡前重新确认、按计数补 Tick；HAL 时间是否补偿是独立设计，Sleep/Stop/Standby 不可混称。

定位：vPortSuppressTicksAndSleep；SysTick 24 位

看门狗与复位

按 LSI 频率范围估算 IWDG；心跳代表检查点，不自动证明驱动或业务前进。区分调试冻结与独立运行。

定位：IWDG、WWDG、复位标志；当前初始化源码

CAN、SPI、ADC 与 OTA

作为通用八股覆盖，未虚构节点已实现这些应用功能；ADC 采样建立时间与分辨率不同，OTA 要处理掉电与试运行确认。

systemd 生命周期

队列与平均关系
